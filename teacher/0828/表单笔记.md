### form 表单 作数据交互-收集用户信息
    action 属性 提交地址/接口地址
    method 属性 请求方式
        post 
        get

### 表单组成: label input select textarea

        label 给表单元素做标注
            label 标签的for属性与input标签的id属性一致 可实现与文字的关联

        input 表单控件元素
            语法:  <input type="val">
            type取值如下:
                text 文本输入框   用于用户名、搜索、账号等
                password 密码框   暗文
                radio    单选框   用于性别 单选题
                checkbox 复选框   用于爱好 协议等

                submit 提交按钮
                button 普通按钮
                reset  重置按钮

                file  文件域       一般用于文件上传
                image 图像域       用于炫酷不太容易实现的按钮


            新增
                tel 电话
                url 网址
                email 邮箱
                number 数值
                date 日期
                time 时间

         
        input 标签的属性
            type 类型
            name 属性 标识字段 且 带着用户信息提交给服务器【后端】
                多个单选框设置name属性一致  实现单选
            value 默认值 用于修改按钮的值 或 输入框的默认值
            src 属性 图像域的路径名称
            checked 默认选中  radio 或 checkbox  
            disabled 禁用
            enabled 默认值 可用
        
        新增属性如下:
            placeholder 输入框的提示文字
            required 必填项
            min 最小值
            max 最大值
            step 步长值  
        

        textarea 文本域   一般用于留言等
            rows 属性 行高
            cols 属性 列宽

        select 下拉列表
            配合option 标签使用
            selected 属性 用于下拉的默认选中
